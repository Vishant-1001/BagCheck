Reference process

How one event is validated

  1. Hash lookup of the bag record
  2. First scan initialises the state
  3. Read the current checkpoint
  4. Ask the graph: does current → next exist?
  5. Classify: valid / duplicate / invalid / unknown
  6. Update state — rejected scans never advance it
  7. BFS: is ARRIVAL still reachable?
Graph + custom queue + custom hash table + BFS/DFS — implemented from scratch in Java, no external libraries.
